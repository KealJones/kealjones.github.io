Things I'm Experimenting With

SquiggleNEW!

A private AI agent that runs entirely in your browser, on your own GPU. It remembers you through a small fact graph, finds earlier conversations with hybrid search, and syncs across your devices through a GitHub repo you own. It can commit code and open pull requests, and the safety rules live in code, not in the prompt.

Try Squiggle or read the code

lm-experiments

Twenty-odd small-model experiments, most written up with the question, the result and what it cost. Can a looked-up snippet teach a small model to write loops in a language it never saw? Can a model learn to ask before it answers? The best results ship: Squiggle Small, a 350M model fine-tuned for Squiggle's tools on a phone, and a Gemma 4 pruned to a 0.6B core and healed by distillation.

The experiments or Squiggle Small

Noodle

An assistant that understands and acts with no language model at all. Everything it knows is a graph of nested concepts, it learns from sources and from being corrected, and it says which word it got stuck on. The latest in a line of attempts: Spoon, Soup, Napkin, Noodle.

Read the design

tp-parse

A forgiving parser for toki pona, a language of about 120 words, built to check machine-translated training data. It accepts 95.8% of a 114,000-sentence real-world corpus and checks all of it in about two seconds.
