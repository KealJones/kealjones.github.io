Things I'm Experimenting With

Squiggle

My answer to one question: how much agent can you get out of a small model in a phone's browser if the harness is good? There's no backend. The model runs on your device, inside an iPhone tab's ~1.9 GB, and your chats and memory sync through a private GitHub repo you own. Big requests become a plan run as many short, fresh turns, so a long task never fills its 6K window. It searches the web, reads pages and works on your repos with git, and the safety rules live in code, not in the prompt.

Try Squiggle or read the code

Tilde

A WebGPU engine I'm building for Squiggle's phone model, because the off-the-shelf ones kept getting the tab killed. iPhone Safari gives a whole tab about 1.9 GB and drops the GPU if one command runs past about three seconds, so Tilde streams weights in tensor by tensor, counts every byte it holds, and splits the work so it never trips the watchdog. On an iPhone 16 it runs Liquid AI's LFM3 1.7B at 12.6 tokens a second, matches llama.cpp token for token, and was the only engine in my tests to finish every prompt size without patches, reading prompts 1.6–1.75× faster than WebLLM.

Read the code and benchmarks

Apotheosis

I have ADHD and I'm bad at seeing my own work, so I built a tool that sees it for me. A small Swift app on my Mac notes what I'm working on (window text and apps; meetings only if I turn them on), strips out anything that looks like a secret before saving, and keeps it in a local database. Nothing leaves the Mac unless I ask Claude to read it through a local MCP server, to draft a standup, find what I promised people, or pull evidence together for a review. The promise detectors are scored against 260 messages I labeled by hand, with 60 held out while I tuned them. I've used it every day for over a year; it only moved to a public repo this month, so the history there is short.

lm-experiments

Thirty-odd experiments, each written up with the question, what happened and what it cost, failures included. Can a model answer from a 360-word packet instead of the whole chat? With Claude models answering, the packet did as well as the full 5,400-word history on 12 test chats, and that idea is behind Squiggle's Fresh mode. Not everything worked, and the write-ups say so: my fine-tune Squiggle Small learned the tool format but missed the bar I set before training, so I called it a no-go, and a Gemma 4 pruned to 0.6B talks again after distillation but isn't usable yet.

Browse the experiments, read the code or see the Squiggle Small results

Four tries at one stubborn idea

An assistant where everything is a concept and no language model does the talking. Napkin reads "what is 5 times three?" by knowing what each word expects ("times" wants two numbers), snaps the pieces together, answers 15 and shows its work. When it hits a word it doesn't know, it looks it up in Wikidata and dictionaries and keeps the answer with its source. I built it four times: Spoon, Soup, Napkin and Noodle. Each got further, and each hit the same wall: messy real text, like "sooo" or "wtf", is hard to hear without a model. Noodle beats Napkin on everyday prompts but still loses to simple baselines on coding ones. That wall is why I went to small models with good harnesses.

Try Napkin or read the design
